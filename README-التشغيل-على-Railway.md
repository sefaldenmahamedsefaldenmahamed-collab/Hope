# 🚀 دليل التشغيل — البوت ثنائي الاستراتيجية V11

## الملفات المطلوبة في مشروع Railway — فقط هذه الأربعة

```
bot.py          ← المحرك: استراتيجيتان (🚀 راكب الترند + 📐 موجات 7/25/99)
web_panel.py    ← اللوحة: لوحتان /trend و /mars — لا توجد أي لوحة أخرى
Dockerfile      ← ينسخ الملفين فقط ويشغّل bot.py
requirements.txt ← احتياط فقط (لو بنيت بدون دوكر)
```

## ⚠️ أهم خطوة: احذف الملفات القديمة من مستودع Railway

المشكلة التي رأيتها في اللوحة سببها أن الملفات القديمة ما زالت موجودة في المشروع (أو أن النشر استخدم نسخة قديمة). افتح مستودع النشر واحذف **نهائياً** كل ملف من هذه القائمة إن وُجد:

| الملف القديم | لماذا يحذف |
|---|---|
| `bot_v9.py` | النسخة الوسيطة القديمة |
| `strategy_mars.py` | كانت تُستخدم مع bot_v9 —هؤلاء اندمجت الآن داخل bot.py |
| `web_panel_mars.py` | لوحة قديمة |
| أي `sniper_v8.db` أو ملف قاعدة بيانات `.db` | بيانات القديمة كلها |
| أي نسخة احتياطية مثل `bot_old.py` أو `web_panel_old.py` | لمنع الاختلاط |

> بعد الحذف يجب أن يبقى في المستودع **4 ملفات فقط** كما في القائمة أعلاه.

## 1) المتغيرات البيئية في Railway → Service → Variables

| المتغير | القيمة |
|---|---|
| `BINANCE_API_KEY` | مفتاحك |
| `BINANCE_API_SECRET` | سرك |
| `TRADE_ENABLED` | `true` |
| `TESTNET` | `true` للتجريبي / `false` للحقيقي |
| `TRADE_SIZE_USDT` | `14` |
| `MAX_TOTAL_TRADES` | `5` |
| `MAX_OPEN_TRADES_TREND` | `5` |
| `MAX_OPEN_TRADES_MARS` | `5` |
| `DB_FILE` | `/data/dual_v11.db` (أو `dual_v11.db` إن لم يوجد مجلد /data) |
| `PORT` | `8080` |

⚠️ لو كان `DB_FILE` ضابطاً على `/data/sniper_v8.db` غيّره إلى `/data/dual_v11.db` حتى لا تكثر بيانات القديمة في اللوحة من جديد.

## 2) إعادة النشر

- من Railway اضغط **Deploy / Redeploy** (بإعدادات جديدة وليس ذاكرة بناء قديمة).
- إذا بقي شكل اللوحة القديم ظاهراً: اعمل **Clear Build Cache** ثم أعد النشر، وتأكد أنك في الخدمة الصحيحة (لا يوجد خدمتان لنفس البوت).
- افتح الرابط: الصفحة الرئيسية تُحوّل تلقائياً إلى **/trend** (🚀 راكب الترند)، وشريط الأعلى فيه تبويبان فقط: راكب الترند وموجات 7/25/99.

## 3) ما تغيّر في هذه النسخة

- اسم قاعدة البيانات الافتراضي أصبح `dual_v11.db` — تبدأ من صفر بدون أي سجلات قديمة.
- لا يوجد في الكود ولا في اللوحة أي ذكر أو منطق أو بيانات تخص الاستراتيجية المحذوفة.
- صفقات القديمة المفتوحة على المنصة (إن وُجدت على الحساب) تعود البوت نسبها كـ🧩 مركز متبنّى ويديرها بقواعد ATR المحافظة حتى تُغلق، وستُحسب في اللوحة مستقلاً عن الاستراتيجيتين.
